扮演 AI 数据科学家的全自主 Web 数据 IDE A fully autonomous, Web-based Data IDE acting as an AI Data Scientist

Next.js 16 TypeScript FastAPI ReAct Agent Loop Native Tool Calling Neon PostgreSQL ChromaDB

基于前沿轻量级大模型构建，具备自主探索数据库、编写执行 Python/SQL 及渲染交互式图表的能力。采用双轨记忆系统 (SQLite + ChromaDB) 与后台异步压缩，提供高鲁棒性的 RAG 及多轮记忆交互 Built around advanced lightweight LLMs, this agentic engine is capable of self-directed database schema exploration, native Python/SQL execution, and interactive chart rendering. It utilizes a dual memory system (SQLite & ChromaDB) with asynchronous compression for resilient RAG and multi-turn interaction.

核心亮点： Key Highlights:

  • 自我纠错机制：很多同类工具问一句答一句，错了就卡在那里。这个系统跑出问题时会看懂报错、当场改好再重跑——用户看不到任何技术细节，只拿到结果 Fixes its own mistakes: Most similar tools answer once and stop, even when the answer is wrong. This one reads the error, corrects itself, and tries again in the same breath — the user never sees the technical mess, just the result.
  • 答案可核对：对话里给出结论，旁边同时列出真正跑过的代码。非技术用户可以只看结论，数据团队则能随时翻开核对——数字和代码来自同一次执行，提高结果的可靠性 Answers you can check: Every conclusion comes with the exact script that produced it. Non-technical users read the result; their data team can open the script and verify it — both come from the same run, so they always match.
  • “记得”先在的对话：系统会把对话整理成要点存下来，下次开新会话还记得先前的结论，比如“revenue 指的是发票总额，不是明细行”。不用每次从头解释背景 Remembers what was settled: Past conversations are distilled into notes, so a new session picks up where the last one left off — things like "revenue means invoice totals, not line items" survive. No need to re-explain the context every time.
