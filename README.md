# Junxian Lyken Lin - Personal Portfolio

Welcome to the source code of my personal portfolio website! 🚀

This is a single-page responsive website designed to showcase my highlighted projects in data science, machine learning, and AI agent development. It features a modern dark-mode aesthetic with glassmorphism UI elements and smooth scrolling animations.

## 🌟 Featured Projects

1. **Agentic RecipeRAG**: A Retrieval-Augmented Generation system with autonomous decision-making and a quantitative evaluation framework.
2. **AI-Powered RFP Optimization & Capacity Management**: A hybrid framework using LLMs and statistical scoring to automate RFP effort estimation (in partnership with CGI).
3. **Vision-language Model Membership Inference Attack**: Achieved Rank #1 in a Kaggle competition focusing on multimodal data privacy and security.

## 🛠 Tech Stack

- **HTML5** for semantic structure
- **CSS3 (Vanilla)** for styling, glassmorphism, glowing gradients, and responsive design
- **JavaScript (Vanilla)** for bilingual toggling (EN/ZH), scroll reveal animations, and interactive navigation

## 💻 Local Development

To run this website locally, simply clone the repository and start a local server:

```bash
git clone https://github.com/LykenL/Personal-Website.git
cd Personal-Website
python3 -m http.server 8000
```

Then open your browser and navigate to `http://localhost:8000`.
